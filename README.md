# A/B-тест эффективности рекламной кампании

Проект по анализу результатов A/B-теста: сравнение конверсии двух рекламных кампаний (коммерческая реклама vs. социальная реклама). Цель — определить, какая кампания эффективнее, и дать бизнес-рекомендацию.

## 🎯 Задача

Компания провела эксперимент: часть пользователей видела **коммерческую рекламу** (группа `ad`), часть — **социальную рекламу** (группа `psa`). Нужно ответить на вопрос: **влияет ли тип рекламы на вероятность покупки?**

## 🛠️ Инструменты

- Python (pandas, numpy, matplotlib, seaborn)
- SciPy (статистика)
- Statsmodels (Z-тест для пропорций)
- Данные: Marketing A/B Testing Dataset (Kaggle)

## 📂 Источник данных

🔗 [Скачать датасет на Kaggle](https://www.kaggle.com/datasets/faviovaz/marketing-ab-testing)

**Примечание:** CSV-файл не включён в репозиторий из-за размера. Для запуска скачайте датасет по ссылке выше и положите файл `marketing_AB.csv` в папку с проектом.

## 📊 Результаты

### 1. Общая информация

| Показатель | Значение |
|------------|----------|
| Всего записей | 588 101 |
| Группа `ad` | 564 577 пользователей |
| Группа `psa` | 23 524 пользователя |

### 2. Конверсия по группам

| Группа | Конверсия |
|--------|-----------|
| `ad` (коммерческая реклама) | **2,55%** |
| `psa` (социальная реклама) | **1,79%** |

### 3. Статистическая проверка

- **Z-статистика:** 7,370
- **P-value:** < 0,0001
- **Вывод:** Разница статистически значима. Реклама работает.

### 4. Размер эффекта

| Показатель | Значение |
|------------|----------|
| Абсолютный прирост | +0,77 п.п. |
| Относительный прирост | **+43,1%** |

## 💡 Бизнес-вывод

Коммерческая реклама показала конверсию **2,55%** против **1,79%** у социальной. Относительный прирост составил **+43,1%** — это статистически значимый результат (p-value < 0,0001).

**Рекомендация:** внедрять коммерческую рекламу как основной канал привлечения. При текущем объёме пользователей это даёт дополнительно **~4 300 покупок** на каждые 100 000 показов.

## 🚀 Как запустить

```
2. Скачайте датасет с Kaggle и положите файл `marketing_AB.csv` в папку с проектом.
3. Запустите скрипт:
```

python ab_test.py

```
